# Przebieg rozliczeń

Dad continues his week from the Plik zbiorczy that Przygotowanie pliku
zbiorczego published: he fills it in Excel, saves and closes it (Gotowość),
then creates the Rozliczenia pracowników from Centrum without pointing to any
file. The Okres list offers only periods with Status okresu `Plik zbiorczy
przygotowany`; `Podgląd bez zapisu` shows the plan per Wykonawca; `Uruchom`,
confirmed in a dialog, is his confirmation of Gotowość. The live view shows
the Szablony pracowników progress, closing Centrum is refused meanwhile, the
Folder rozliczeń pracowników appears at once, and the Status okresu moves to
`Rozliczenia pracowników gotowe`. The result lists every Rozliczenie
pracownika with the Wykonawca, his orders and `Otwórz`, marks the empty one
`pusty`, and opens the Folder rozliczeń pracowników as its main action. Every
stop and problem has three parts.

## Sub-features

- `przebieg-gotowosc`: the harness fills the Plik zbiorczy of `06_12_10_2026` the way Dad does in Excel (a quantity in N of every Wiersz danych), saves it, and leaves no lock file.
- `przebieg-wybor-okresu`: the board row's next step opens Uruchomienia with tile `Przebieg rozliczeń` chosen, the last complete period preselected, the Plik zbiorczy name in `Pliki`, and the reminder; only periods with a prepared Plik zbiorczy are offered.
- `przebieg-plik-zbiorczy-otwarty-w-excelu`: with the Plik zbiorczy of `06_12_10_2026` open in Excel (its lock file `~$…` next to it), the start card warns `Plik zbiorczy jest otwarty w Excelu. Zapisz go i zamknij. Jeśli Excel jest zamknięty, usuń z tego samego folderu pozostawiony plik ~$Rozliczenie 06_12_10_2026 - zbiorcze.xlsx.` (the lock file may be left behind by an Excel that crashed), `Uruchom` is off, `Podgląd bez zapisu` and the reminder stay on; once the lock file is gone, Dad's return to the window clears the warning without a reload.
- `przebieg-wzorzec-pozostawiony-plik-blokady`: a lock file `~$Wzorzec rozliczenia pracownika.xlsx` left by a crashed Excel turns off `Uruchom` with its own warning and hides the reminder about the Plik zbiorczy, which does not block; after a `Podgląd bez zapisu` stopped on it, Dad deletes it and `Nowe Uruchomienie procesu` shows the card without the warning, with no return to the window.
- `przebieg-podglad`: before a Wycena w efenix the `Następny krok` card offers `Uzupełnij plik zbiorczy` and no Podgląd bez zapisu, after one that needs checking `Wyceń w efenix`; once the period's Wycena w efenix ended OK, it offers `Utwórz rozliczenia pracowników` with three done steps of Droga okresu; in each, the card's heading, current step and main button and the row's main button name one step, and its `Podgląd bez zapisu` shows the figures (`Wiersze danych`, `Planowane szablony`, `Puste szablony`) and the open `Plan plików` (per Wykonawca his file and orders, `pusty` for the one without orders, nothing to open), creates no Folder rozliczeń pracowników, and appends one DRY-RUN record to the Przebieg rozliczeń metrics file.
- `przebieg-potwierdzenie`: `Uruchom` on the result card asks `Uruchomić z zapisem?` with the reminder, the Gotowość line, no no-preview warning, and the sentence of `GET /api/periods/<token>/without-quantity` (Gotowość types only N, so the rows without rule stay listed).
- `przebieg-na-zywo`: during the RUN the live view shows `Szablony pracowników · <Wykonawca>` with `x z 4` and the live counters (`Wiersze danych`, `Zapisane szablony`, `Puste szablony`, `Problemy`) from the projection, and `POST /api/shutdown` is refused with `409`.
- `przebieg-znak-uruchomienia`: on Okresy during the RUN the menu marks `Uruchomienia` with `Trwa Uruchomienie` and the header shows the link `Trwa Uruchomienie`, which leads back to the live view, where the link is gone.
- `przebieg-zapisane`: the result `Rozliczenia pracowników gotowe` with `Zapisane szablony` 3 and `Puste szablony` 1 lists `Rozliczenia pracowników (4)` without a click, the empty one marked `pusty` with `0 zleceń w tym tygodniu`; the Folder rozliczeń pracowników holds the four files and no staging folder is left; metrics hold RUN OK and DRY-RUN OK marked `centrum`; the Centrum log has the end line.
- `przebieg-otwieranie`: each row's `Otwórz` opens exactly that Wykonawca's Rozliczenie pracownika, the main action `Otwórz folder rozliczeń pracowników` opens the folder, one line in `opened.jsonl` per click; a Wykonawca name leading out of the folder is refused with `404`.
- `przebieg-odczyt-po-uruchomieniu`: in the same tab, the Historia tab shows the finished RUN and its preview at the top, and `Nowe Uruchomienie procesu` → `Przebieg rozliczeń` no longer offers the closed period: both are read again after the Uruchomienie procesu.
- `przebieg-status-okresu`: Tablica okresów shows `Rozliczenia pracowników gotowe` and `Następny krok` shows `Okres zamknięty`.
- `przebieg-nienadpisywanie`: a second RUN of the closed period (started through the API, since the Okres list no longer offers it) stops in three parts without a full path and leaves the files byte-identical.
- `przebieg-wymaga-sprawdzenia`: `Podgląd bez zapisu` of `29_05_10_2026`, whose Plik zbiorczy has a Wykonawca missing from the konfiguracja wykonawców, ends `Podgląd wymaga sprawdzenia · nic nie zapisano` with an amber icon, the problem in three parts, and `Uruchom ponownie` instead of `Uruchom`.
- `przebieg-nieznany-wykonawca`: `Uruchom` for the same period stops on that Wykonawca, writes nothing, and its `Co zrobić` starts with the advice on column H without sending Dad to `Podgląd bez zapisu` for rows, since the preview's problem names none.

## How to get to it (user POV)

- Okresy → card `Następny krok` → `Podgląd bez zapisu` (when the last complete period has Status `Plik zbiorczy przygotowany` and its last Wycena w efenix ended OK).
- Okresy → Tablica okresów → row button `Utwórz rozliczenia pracowników, okres <token>` (beside `Wyceń w efenix` before a Wycena w efenix with the result OK) → Uruchomienia with tile `Przebieg rozliczeń` and that period chosen.
- Sidebar `Uruchomienia` (`#/uruchomienia`) → `Nowe Uruchomienie procesu` → tile `Przebieg rozliczeń`.

## Gotchas

- The counters strip is a description list, not a landmark; find it with `live.locator('dl[aria-label="Liczniki"]')`. Its text joins label and value without a space (`Zapisane szablony1`).
- Without the pacing file the synthetic RUN ends in milliseconds: the live progress cannot be seen, and a `POST /api/shutdown` sent after the end really closes Centrum. Keep the pacing on until the refusal and the sign on Okresy are recorded; at 2500 ms per Szablon pracownika both fit before the last one ends.
- After the RUN, `06_12_10_2026` leaves the Okres list (its Status okresu is `Rozliczenia pracowników gotowe`); the Nienadpisywanie step therefore starts through the API, as a second tab or a stale page would.
- `Plan plików` is open after a preview and its file names are plain text, since the files do not exist yet; after a RUN table `Rozliczenia pracowników` replaces it.
- The tab drops a repeated click on the same file for 1.5 s after the server's answer, so each `Otwórz` names another file.
- The result toast covers the bottom-right corner for a few seconds after a RUN.
- `Uruchom` is also the confirmation dialog's button; scope the second click to the alertdialog.
