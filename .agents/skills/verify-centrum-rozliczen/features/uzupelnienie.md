# Uzupełnienie pliku zbiorczego

After Przygotowanie pliku zbiorczego, Dad types the Ilości do uzupełnienia in
Excel. Three entries lead to the period's summary: the card `Następny krok` on
Okresy and the Tablica okresów row offer `Uzupełnij` for a period with Plik
zbiorczy przygotowany, and the written Plik zbiorczy's result card shows the
same summary with `Uzupełnij`. Droga okresu has `Uzupełnienie w Excelu` as its
current step. The summary is at
`#/uzupelnienie/<token>`: a counter „x z y” and the row numbers for `Wiersze bez
reguły` and `Wiersze z opisu` (done rows crossed out, a kind with no rows or
all rows done ticked, never red), how many rows hold a value in each column
from the technician's description, `Otwórz Plik zbiorczy` when the Plik
zbiorczy is in the Folder okresu, and `Gotowe, rozlicz
pracowników`, which opens Przebieg rozliczeń with the period chosen; its
dialog `Uruchomić z zapisem?` lists the rows still without quantity. Centrum reads
the saved Plik zbiorczy on every read, also while Excel holds it, and never
changes it. Each kind with rows opens its own page at
`#/uzupelnienie/<token>/<kind>`: a read-only table like Excel with only that
kind's rows, the row number and WYKONAWCA, URZĄDZENIA, CZYNNOŚCI and CZYNNOŚCI
ZREALIZOWANE pinned on the left, all 29 columns N:AP scrolling sideways under
their letter and price-list name, the tool's values grey, a row to fill yellow,
and Dad's value green in a green row. A Plik zbiorczy it cannot read is a calm
three-part Komunikat. The summary and the kind pages are live (#419): while
visible they ask every 3 s for the saved version
(`GET /api/periods/<token>/collective-file-version`, `stat` only) and read the
view again only when it changed; a failed read keeps the last good state with
its time for about a minute, then the Komunikat. After Przebieg rozliczeń
(Status okresu `Rozliczenia pracowników gotowe`) both pages are a preview:
`Przebieg rozliczeń się odbył · tylko podgląd`, no `Gotowe` and no hint about
saving in Excel, and a row Dad left empty is grey with the words „bez ilości”
on screen, not yellow.

## Sub-features

- `uzupelnienie-wynik`: the result card of Przygotowanie z zapisem has region `Uzupełnienie pliku zbiorczego` with the summary of `GET /api/periods/<token>/quantities-to-fill` and `Uzupełnij`, which opens the same summary; Wstecz returns to the result. Driven from `przygotowanie-kontynuuj`, the only written Przygotowanie without a stop.
- `uzupelnienie-wynik-bez-starej-kopii`: with the summary page's copy older than the file (harness: Dad's value in Y18 while the summary is open), Wstecz to the result card shows `1 z 2` and never the older `0 z 2`: the card reads without the copy.
- `uzupelnienie-wynik-na-zywo`: with Excel next to Centrum, values Dad types in Y18 and Y20 turn the result card's `Wiersze bez reguły` into `2 z 2` within a few seconds, without a click, focus, tab switch or reload; the card has the hint `Nie widzisz zmian? Zapisz w Excelu (Ctrl+S).` and asks nothing about the Plik zbiorczy while the tab is hidden.
- `uzupelnienie-wynik-po-przebiegu`: with the Folder rozliczeń pracowników of the period present (harness), the result card after Dad returns to Centrum reads `bez ilości` next to the rows not done and has no `Nie widzisz zmian?` hint; without the folder the hint is back.
- `uzupelnienie-wynik-bez-odpowiedzi`: while the server gives no answer about the Plik zbiorczy (harness), the result card shows an alert `Nie udało się odczytać Pliku zbiorczego` with `Spróbuj ponownie` instead of going blank, and the summary by itself once the server answers again.
- `uzupelnienie-wynik-bez-centrum`: while neither the version checks nor the reads of the Plik zbiorczy get an answer (harness), the result card shows the alert `Nie udało się odczytać Pliku zbiorczego` after one version check, without a focus or a click, instead of the old summary as live, and the summary by itself once Centrum answers again.
- `uzupelnienie-wynik-po-starcie`: after Centrum is closed and started again, the card `Ostatnie Uruchomienie` (from Logi) of the same Przygotowanie has the same summary.
- `uzupelnienie-tablica`: only the Tablica okresów row with Status `Plik zbiorczy przygotowany` has `Uzupełnij, okres <token>`, and it opens that period's summary.
- `uzupelnienie-droga`: Droga okresu on `Następny krok` has four steps (Plik zbiorczy, Uzupełnienie w Excelu, Wycena w efenix, Rozliczenia pracowników) and one current step (`aria-current="step"`), `Uzupełnienie w Excelu`, after one done step.
- `uzupelnienie-karta`: the card `Następny krok` for the last complete period with Status `Plik zbiorczy przygotowany` and no Wycena w efenix has heading `Uzupełnij plik zbiorczy`, `Uzupełnij` as its primary action and `Wyceń w efenix` next to it.
- `uzupelnienie-podsumowanie`: `Uzupełnij` opens `#/uzupelnienie/06_12_10_2026` with the period token in the title row; the counters, row numbers and column counters equal `GET /api/periods/<token>/quantities-to-fill`; the sidebar highlights Okresy; the view is measured as page `uzupelnienie`.
- `uzupelnienie-wpis-taty`: one value Dad types in column Y of row 18 (harness, openpyxl) while the summary is open makes, without a click or reload, row 18 done (`1 z 2`) and column Y count one more row; nothing else changes, and an unchanged file is not read again.
- `uzupelnienie-tabela-bez-reguly`: the region `Wiersze bez reguły` links to `#/uzupelnienie/06_12_10_2026/without_rule`; its table equals `GET /api/periods/<token>/quantities-to-fill/without_rule` row by row and cell by cell, Dad's value in Y18 is a green cell in the done row 18, a tap on a column header or on CZYNNOŚCI ZREALIZOWANE shows the full text, the row number stays put while N:AP scroll sideways, and the answer has no address, order number or UMOWA.
- `uzupelnienie-tabela-z-opisu`: the same for `Wiersze z opisu` (`#/uzupelnienie/06_12_10_2026/from_description`, row 19, no tool values).
- `uzupelnienie-tabela-na-zywo`: a value Dad types in Y20 while the table `Wiersze bez reguły` is open turns row 20 done with a green cell, without a click or reload; deleting it turns the row back to fill.
- `uzupelnienie-blokada-excela`: Excel's lock file `~$…` next to the Plik zbiorczy changes neither the server's answer nor the screen.
- `uzupelnienie-odczyt-nieudany`: a Plik zbiorczy Centrum cannot read (being saved) keeps the last good state on screen with `Stan z <HH:MM>.` and no Komunikat; once it reads again the time disappears by itself.
- `uzupelnienie-otworz`: `Otwórz Plik zbiorczy` opens the period's Plik zbiorczy (`opened.jsonl`).
- `uzupelnienie-powrot`: the link `Okresy` leads back and Wstecz returns to the same summary.
- `uzupelnienie-gotowe`: with Excel closed, `Gotowe, rozlicz pracowników` opens `#/uruchomienia` with Przebieg rozliczeń and `06_12_10_2026` chosen; the sentence of `GET /api/periods/<token>/without-quantity` names the summary's rows not done (`2 wiersze bez ilości: 19, 20`), and the setup itself carries no rows.
- `uzupelnienie-gotowe-potwierdzenie`: `Uruchom` opens `Uruchomić z zapisem?`, which says `2 wiersze bez ilości: 19, 20` and keeps `Uruchom` enabled; `Anuluj` closes it.
- `uzupelnienie-gotowe-po-podgladzie`: `Podgląd bez zapisu` on the form, then `Uruchom` on the result card opens the same dialog with `2 wiersze bez ilości: 19, 20` (Dad's usual path); `Anuluj` closes it.
- `uzupelnienie-gotowe-bez-odczytu`: with the Plik zbiorczy of `29_05_10_2026` damaged (harness, restored after), `Gotowe` on its summary chooses that period, not the preselected one; its rows answer `{state: unread}`, and the dialog says `Nie udało się sprawdzić wierszy bez ilości` with `Uruchom` enabled.
- `uzupelnienie-po-przebiegu`: with the Folder rozliczeń pracowników of `06_12_10_2026` present (harness, removed after), the Tablica okresów says `Rozliczenia pracowników gotowe`; the summary says `Przebieg rozliczeń się odbył · tylko podgląd`, its answer has `settled: true`, row 18 (Dad's value) done and rows 19 and 20 `without_quantity` with `bez ilości` on screen next to their numbers (image `Bez ilości`), there is no `Gotowe, rozlicz pracowników`; on the kind page `Wiersze bez reguły` row 20 is no longer yellow as before the folder and not green like row 18, reads `bez ilości` on screen under its number, and the hint is `Szare zostały bez ilości.`
- `uzupelnienie-bez-pliku`: a period without a Plik zbiorczy shows the server's three-part Komunikat (label `Komunikat`), not a failure, `Otwórz Plik zbiorczy` only when the file is in the Folder okresu (`collective_file_exists`), on the summary and on `#/uzupelnienie/15_21_09_2026/without_rule` alike, and the Centrum log has `uzupelnienie-odczyt-nieudany` with the period.
- `uzupelnienie-gotowe-bez-okresu`: `Gotowe` on that summary opens Przebieg rozliczeń with the preselected `06_12_10_2026` and an alert `Okresu 15_21_09_2026 nie ma do wyboru, więc wybrany jest 06_12_10_2026.`, never a silent switch.

## How to get to it (user POV)

- Okresy → card `Następny krok` → `Uzupełnij` (when the last complete period has Plik zbiorczy przygotowany).
- Okresy → Tablica okresów → `Uzupełnij` in the row of any period with Plik zbiorczy przygotowany.
- Uruchomienia → result of Przygotowanie pliku zbiorczego z zapisem → `Uzupełnij`.
- The address `#/uzupelnienie/<token>` directly, also after a reload or Wstecz.

## Gotchas

- Restore the Plik zbiorczy: `przebieg-rozliczen` continues from it, and a value left in Y18 would reach a Rozliczenie pracownika and the Kontrola ilości.
- `Uzupełnij` has role `button`, not `link`: it is a Base UI `Button` rendered as `<a>`, like the bell.
- Headless Chromium reports the tab as visible, so the page keeps asking for the saved version during the whole drive; a step that counts requests counts only its own.
- `Gotowe` only fills the Przebieg form (`setDraft`, in page memory); a reload drops it. The drive reloads after the last `Gotowe` so the next feature starts from the preselected process.
- The rows without quantity are the listed kinds' rows not done (bez reguły and z opisu), never a row the Reguły ilości cover; an unreadable Plik zbiorczy makes them `unread`. The dialog reads them for its period when the card shows it, never the setup, because one read takes Dad's laptop over a second.
- The preview in `uzupelnienie-gotowe-po-podgladzie` adds one DRY-RUN of Przebieg rozliczeń to the week before `przebieg-rozliczen`; that feature counts its records from its own start.
- The kind pages' row texts are workbook content: `run.api` would keep them in the evidence, and `centrum_self_test.py` rejects evidence with `ROW_MARKER`, so the drive saves the table answer without them.
- Delete the lock file in `finally`; a leftover `~$…` makes Przebieg rozliczeń stop with „Plik zbiorczy otwarty”.
- Remove the harness's `Rozliczenie pracowników 06_12_10_2026` in `finally`: a leftover folder closes the period, and `przebieg-rozliczen` would stop with Nienadpisywanie instead of settling it.
