# Przygotowanie pliku zbiorczego

Dad prepares the Rozliczenie wewnętrzne and the Plik zbiorczy of a period
from Centrum: he picks the period (the last complete one is preselected),
looks at the plan without writing (`Podgląd bez zapisu`, DRY-RUN), confirms
the write (`Uruchom`, RUN) after a reminder to close the Rejestr zleceń, sees
the stages live over SSE, decides about an incomplete period in a dialog, and
gets the result: stops and warnings separately, each in three parts. Every
Uruchomienie procesu appends to the process's metrics file, and the history
marks it as started from Centrum.

## Sub-features

- `przygotowanie-wybor-okresu`: the board row's next step opens Uruchomienia with the last complete period preselected, the files from the settings, and the reminder.
- `przygotowanie-rejestr-otwarty-w-excelu`: with the Rejestr zleceń open in Excel (its lock file `~$…` next to it), the start card warns `Rejestr zleceń jest otwarty w Excelu. Zapisz go i zamknij. Jeśli Excel jest zamknięty, usuń z tego samego folderu pozostawiony plik ~$<Rejestr zleceń name>.` (the lock file may be left behind by an Excel that crashed), `Uruchom` is off, `Podgląd bez zapisu` and the reminder stay on; once the lock file is gone, Dad's return to the window clears the warning without a reload.
- `przygotowanie-podglad`: `Podgląd bez zapisu` on the `Następny krok` card, double-clicked, starts one DRY-RUN without an error toast, shows the plan (counts, warnings, Zlecenia na dzień, both file names as plain text), writes nothing, and appends one DRY-RUN metrics record. The plan's Ilości usług warnings name Plik zbiorczy rows and keep the preview OK, so `Uruchom` stays in the result.
- `przygotowanie-podglad-po-odswiezeniu`: after a reload, the confirmation of the previewed period has no no-preview warning, and a period without a successful preview still has it; `GET /api/runs/setup` marks `previewed` per period from the metrics history.
- `przygotowanie-potwierdzenie`: after a reload, `Uruchom` in the preview's result asks `Uruchomić z zapisem?` with the reminder and without the no-preview warning; its `Uruchom`, double-clicked while the dialog closes, starts one RUN without an error toast.
- `przygotowanie-decyzja`: an incomplete period waits in the decision dialog with Zlecenia na dzień and focus on `Przerwij bez zapisu`; the live counters behind it show the projection's `Ostrzeżenia`; a second Uruchomienie and closing Centrum are refused; the dialog survives a reload.
- `przygotowanie-znak-decyzji`: while the decision waits, on Okresy the menu marks `Uruchomienia` with `Czeka na decyzję` and, where the dialog does not open, the header shows the link `Czeka na decyzję`, which leads back to the dialog on Uruchomienia.
- `przygotowanie-przerwij`: `Przerwij bez zapisu` ends in a calm banner `Przerwano` (not red, no `Diagnoza`) with `Nic nie zapisano, Twoje pliki są bez zmian.` and the three-part message worded for Centrum, writes nothing, and its `Otwórz Rejestr zleceń` writes the Rejestr zleceń to `opened.jsonl`.
- `przygotowanie-podwojne-klikniecie`: `Uruchom ponownie` double-clicked starts one RUN, `Kontynuuj` clicked three times while the stream lags sends one decision and its buttons wait for the stream, no error toast appears, and the result's main action `Otwórz Plik zbiorczy` double-clicked opens the Plik zbiorczy once.
- `przygotowanie-kontynuuj`: the RUN that `Uruchom ponownie` and `Kontynuuj` started in `przygotowanie-podwojne-klikniecie` finished `Plik zbiorczy przygotowany · wymaga sprawdzenia` with both period files published and the preview's warnings in its result card; metrics hold DRY-RUN OK, RUN BLAD_KRYTYCZNY, RUN WYMAGA_SPRAWDZENIA, so the double clicks started no second Uruchomienie; the Centrum log has the start and end of each Uruchomienie.
- `przygotowanie-otwieranie`: after the RUN each period file name in list `Pliki okresu`, Rozliczenie wewnętrzne and Plik zbiorczy, is a button that opens its own file.
- `przygotowanie-status-okresu`: the Tablica okresów shows `Plik zbiorczy przygotowany` and the next step moves on.
- `przygotowanie-nienadpisywanie`: a second RUN of the same period stops `Do poprawy` (`for_tata`, no file to open) and leaves both files byte-identical.
- `przygotowanie-historia`: the `Historia` tab lists the four runs without the `.cmd` badge; `/api/metrics` marks them `centrum`.

## How to get to it (user POV)

- Okresy → card `Następny krok` → `Podgląd bez zapisu` (when the last complete period has no period files).
- Okresy → Tablica okresów → row button `Przygotuj plik zbiorczy, okres <token>` → Uruchomienia with that period chosen.
- Sidebar `Uruchomienia` (`#/uruchomienia`) → `Nowe Uruchomienie procesu`; tabs `Uruchomienie` and `Historia`.

## Gotchas

- `Run.capture` waits for running animations, and a running stage's bar loops forever. Capture only in a settled state (finished, or waiting for the decision, when no stage runs).
- The Uruchomienie runs in the server's worker thread; wait on `/api/runs/current` (`finished_result` in `drive/common.py`), not on a fixed delay.
- Count metrics records through `/api/metrics`, not by lines: the fixture's Przygotowanie file ends with an invalid record, which the metrics store cuts off on the next append.
- The start card reads `/api/runs/setup` again on `focus` and `visibilitychange` only; after changing a lock file, fire `focus` or the card keeps the old answer.
- The no-preview warning follows the server: a period counts as previewed when the metrics history (Centrum or `.cmd`) has a DRY-RUN with result OK for it. The fixture's synthetic history already has such records for `15_21_09_2026`, `22_28_09_2026`, and `29_05_10_2026`, so use `08_14_09_2026` for the warning.
- The result toast appears only after a finished write and covers the bottom-right corner for a few seconds.
- `Uruchom` is also the confirmation dialog's button; scope the second click to the alertdialog.
- A repeated click is a no-op until the stream shows its effect. The decision buttons and the setup card's `Uruchom` and `Podgląd bez zapisu` are disabled then: click them again with `force=True`, or Playwright waits for them to be enabled. The result's `Uruchom ponownie` and `Uruchom` and the `Następny krok` button stay enabled and drop the repeat in the tab.
- Two identical stops „dla taty” in a row are a Powtórka: the second offers `Diagnoza` instead of `Uruchom ponownie` (`diagnoza.md`). The drive's stops keep `Uruchom ponownie` only because a finished Uruchomienie stands between them.
- The stream follows the tab's visibility (`watchRunEvents`); faking `document.visibilityState` pauses it without a reload. Always restore it (`finally`), or every later step sees a stale Uruchomienie.
